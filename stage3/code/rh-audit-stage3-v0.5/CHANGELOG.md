# v0.5

Adds --phase uses/use-smoke, a bounded raw-expression argument scanner,
mandatory isolated fixtures, ten frozen targets, strict occurrence parsers,
source provenance and explicit truncation records. No project mutation or
Comparator control. New Lean code is server-gated, not locally compiled.

# v0.4 — selected consumers and compiled provenance

Adds an eight-target consumer probe and byte-identical isolated provenance
fixture. Records type/body reference lists and module ownership from compiled
metadata, validates record completeness, and collects the identified source
modules against pinned git contents. Source selection prioritizes targets,
then direct-reference modules, then one import level. All caps are explicit.
Adds protocol, Python tests and resource-preserving failure handling.
New Lean files require the server fixture gate; no local Lean test is claimed.
